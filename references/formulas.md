# 拆解公式、复刻公式与验证方法

## 1. 总公式：把阅读动机拆开

**拆解公式 D = 人群 P + 触发场景 S + 具体冲突 C + 承诺 V + 证据 E + 行动 A + 边界 B。**

这是分析槽位，不是数学预测模型。各项不要求全在标题中；不要给槽位随意加权后伪装成爆款概率。

|槽位|要问的问题|可接受证据|容易误判|
|---|---|---|---|
|P 人群|谁会觉得说的是自己|标题称谓、场景限制、评论自述|给所有人贴同一焦虑|
|S 场景|什么时候问题最明显|一个动作、地点、时刻、镜头|“现代人生活节奏快”|
|C 冲突|原以为怎样，实际怎样|具体不便、预期落差、取舍|把普通差异写成灾难|
|V 承诺|看完能知道/做什么|正文确实兑现的记录或方法|标题许诺结果，正文只有感叹|
|E 证据|凭什么相信|同条件照片、步骤、尺寸、账单、实测记录|大词、表情包、虚构故事|
|A 行动|读者下一步能做什么|量一下、核对清单、讨论具体问题|只会“收藏关注私信”|
|B 边界|结论在什么情况下成立|适用条件、未完成项、例外|加一句“因人而异”却仍保证效果|

分析时写完整证据链：“原创假设例：参考文案描写刚洗又塌 → 预期与观察落差容易识别 → 可能降低理解成本（推断） → 可迁移为整理后又乱；没有当前互动数，不能据此认定带来高点击。”

**复刻公式 R = 保留读者需求与叙事关系 + 替换人群/场景/动作 + 接入自己的证据 + 重写承诺与边界。**

变更清单：保留什么、为什么可迁移、换成什么、用什么证明、哪些不能照搬。至少改变事实材料和表达组织；只改品牌、人称、形容词不算完成。没有可证明体验时，切换为待验证方案。

## 2. 五种可选结构及视频模型

### M1 扎心反问 → 具体困扰

拆解：熟悉场景 → 一个刺眼的小变化 → 想确认原因/办法 → 一条可执行动作。

标题骨架：“[已经做过的动作]，怎么[问题仍在]？”；首图只留“[看得见的困扰]”。正文先复现场景，再说观察、当前尝试和未解问题。不要把“你再不改就晚了”当钩子。

原创结构示意：“洗完头还是痒，头发也一直掉”。迁移：“抽屉刚整理好，怎么找根线还要翻？”需要真实乱点和取物过程，不能仅摆拍一张整齐图。

### M2 真相科普 → 可核查解释

拆解：常见误解 → 能核验的信息 → 影响选择的变量 → 低门槛核对。

标题骨架：“[现象]，先看一下[可检查变量]”。结构：我原先关注 A → 资料/规格支持 B → 可以先查 C → B 不能解释的部分。个人经历不能替代专业依据；“真相”二字不是必写。

迁移：“隔板放不进去，先量抽屉里面”。证据为内径、净高、产品尺寸与照片。不要把猜测写成“原来所有人都量错了”。

### M3 踩坑避雷 → 一个真实取舍

拆解：原计划 → 实际障碍 → 有代价的细节 → 可重复检查的方法。

标题骨架：“[物品/方案]没选成，我漏看了[一个条件]”。必须有真实购买/筛选记录；没有就写“下单前先查这几项”，不编“花了几千冤枉钱”。批评具体不适配，不凭空判产品差。

迁移：“盒子挑好了，才发现抽屉关不上”。需要确认是否真的发生；否则改成“买抽屉盒前，别漏量净高”。

### M4 记录打卡 → 可比较的过程

拆解：起点 → 同条件记录 → 一个变化 → 仍未改变的部分 → 下一次记录计划。

标题骨架：“[场景]先留个底，之后照这个位置拍”。时间线只能填真实日期；单张照片不能扩写成半年结果。对照尽量固定光线、机位、使用条件，不把光影差异当产品效果。

迁移：“先把桌面拍下来，下一次从这个角度看”。没有后续记录时只交首日稿，不写“坚持七天效果惊人”。

### M5 测评清单 → 帮读者做选择

拆解：具体任务 → 少量有区分力的标准 → 同口径结果 → 适用人群 → 取舍。

标题骨架：“选[品类]，我先看[两个/三个实际标准]”。标准必须影响结果，不列“颜值高、质量好、性价比高”三句空话。多个产品未实测时写选购对照表，不叫横评。

迁移：“抽屉隔板先看净高，再看能不能固定”。数据按实际资料填写，尺寸用单位，价格带日期。不偷渡默认推荐。

### V 过程视频

可用 30–60 秒作为附件参考，不强制时长。开场 0–3 秒展示问题；随后演示动作与证据；结尾只给一个判断。每段写机位、手部动作、字幕、声音和所需材料。效果前后对比必须来源真实且条件可比；没有素材时给分镜不声称成片。

## 3. 标题、首图、正文三层接力

首图 = 一眼可识别的场景/问题；发布标题 = 场景+动作/悬念；开头 = 立即把读者带进一次具体事情。

首图“又找不到线了” → 标题“桌面收纳先别买盒子，先看看线都堆在哪” → 开头“充电线、转接头和备用线混在一起，找一个就得全拎出来。”最后一句只在事实卡有这个细节时用。

标题通常可先写 3 个方向：场景型、落差型、方法型，再按正文证据选一个。避免先写最夸张的标题再编故事兑现。首图字数、色块、手写体依据实际画面，不把固定数字/字体视作平台规则。

## 4. 变量与证据的替换表

|原案例结构|换品类后必须重写|不能迁移|
|---|---|---|
|头皮近景让问题可见|让目标困扰可见的镜头：线材混放、抽屉净高、杯口清洁死角|拿头皮照片证明收纳产品|
|洗完仍油的预期落差|整理后仍找不到物品等真实落差|“治好”“救回来”等结果承诺|
|固定角度记录|相同机位、相同负载的过程记录|虚构时长和前后效果|
|评论中反复出现的问题|本品类评论真实提问与用户自己的目标|跨账号假装多人追问|
|参考主色/首图|适配新场景、可读性和真实素材|把红色小块当万用品类爆点|

## 5. 实验与复盘口径

|指标|计算|前提|
|---|---|---|
|封面点击相关指标|后台定义的点击/曝光|名称与平台后台一致，不混用阅读|
|阅读收藏率|收藏/阅读|两者同时间窗且后台有阅读数|
|阅读评论率|评论/阅读|评论为条数，不能解释为独立评论人数|
|留咨率|有效留咨人数/明确约定的曝光或阅读分母|需真实后台与去重记录，注明采用哪种分母|
|公开互动量|赞+藏+评|三项可见；不等于曝光、成交或转化|

没有分母留空。24 小时、72 小时、7 天是便于复盘的观察窗口，不是官方推荐规则。测试同一方向的内容时尽量保持人群、题材与发布时间可比，一次主要改封面、标题或开头其中一个；不同帖子仍有天然噪声，不能作严谨因果证明。小样本优先积累，不因一篇低互动就下“限流”结论。

不采用没有定义与依据的相似度阈值作为平台规则。实际检查新稿是否沿用了原文独特叙事、段落次序和关键比喻；同主题系列至少在场景证据与表达结构上有实质变化。
